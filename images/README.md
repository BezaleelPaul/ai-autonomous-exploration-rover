# Project Image Catalog & Documentation Index

This directory contains the photographic documentation, component photos, assembly stages, and testing/telemetry screenshots for the **360° Vision Self-Balancing Rover** project.

## Directory Structure

```text
images/
├── components/          # Hardware modules, actuators, sensors, and power elements
├── assembly/            # Step-by-step chassis mechanical and electrical assembly
└── testing_telemetry/   # Firmware flashing, live YOLO inference, and web streams
```
